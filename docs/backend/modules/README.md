# Módulos del backend

Este directorio será el catálogo canónico de módulos del monolito. Cada módulo
debe tener un documento propio y declarar sus límites antes de depender de otro.

## Catálogo

| Módulo | Estado | Responsabilidad | Documento |
|---|---|---|---|
| Core de recursos y activos | Por definir | Gestión común de recursos y activos domésticos | Pendiente |
| Eventos temporales | Visión | Hechos o periodos que afectan a recursos | Pendiente |
| Mantenimiento (CMMS) | Visión | Planificación y seguimiento del mantenimiento | Pendiente |
| Warehouse | Visión | Existencias, ubicaciones y movimientos | Pendiente |
| Planificador de tareas | Visión | Organización y seguimiento de tareas | Pendiente |

Usa [`module-template.md`](module-template.md) para documentar un módulo nuevo.
