# Skills de backend

Este catálogo contiene capacidades reutilizables exclusivas del backend, por
ejemplo crear un módulo, diseñar una migración, añadir un endpoint o verificar un
contrato de adaptador.

| ID | Skill | Estado | Definición | Implementación |
|---|---|---|---|---|
| — | Aún no hay skills de backend registradas | — | — | — |

Cada entrada debe seguir la
[`plantilla común`](../../common/skills/skill-template.md) y añadirse también al
[`catálogo global`](../../common/skills/catalog.md).
