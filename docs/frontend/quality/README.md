# Calidad del frontend

Este directorio define cómo comprobar comportamiento, accesibilidad y calidad
visual de la aplicación web.

## Contenido previsto

- Pruebas unitarias de dominio y lógica de presentación.
- Integración de casos de uso, estado y adaptadores.
- Contratos del cliente REST y recorridos end-to-end críticos.
- Pruebas de componentes, interacciones y regresión visual.
- Accesibilidad automática y manual.
- Matriz responsive de tamaños, navegadores y métodos de entrada.
- Rendimiento, presupuestos y mediciones reproducibles.
- Formato, lint, tipos, build y puertas de CI.

Las pruebas deben priorizar comportamiento observable y evitar depender de
detalles internos del framework.
