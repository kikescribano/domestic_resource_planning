# Plantillas documentales

Este directorio reúne los puntos de partida reutilizables para mantener una
estructura consistente sin imponer contenido irrelevante.

## Plantillas

- [`document-template.md`](document-template.md): documento general con metadatos,
  alcance, decisiones abiertas, referencias e historial.
- [`../architecture/decisions/ADR-template.md`](../architecture/decisions/ADR-template.md):
  decisión arquitectónica duradera.
- [`../skills/skill-template.md`](../skills/skill-template.md): definición y
  contrato de uso de una skill.
- [`../../backend/modules/module-template.md`](../../backend/modules/module-template.md):
  límites y diseño de un módulo del backend.

Al crear un documento, elimina las secciones que no apliquen y añade el resultado
al índice de su directorio. No modifiques la plantilla para reflejar una decisión
concreta del producto.
