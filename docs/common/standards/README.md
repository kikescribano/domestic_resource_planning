# Estándares transversales

Este espacio recoge convenciones que deben aplicarse de igual forma en frontend y
backend. Una regla exclusiva de un componente debe permanecer en su propia área.

## Estándares previstos

- Documentación, nomenclatura y revisión de enlaces.
- Gestión de versiones y compatibilidad.
- Principios de seguridad y tratamiento de datos sensibles.
- Criterios comunes de observabilidad y correlación.
- Definición de terminado y evidencias de calidad.
- Convenciones de contribución y revisión técnica.

Cada estándar debe incluir motivación, reglas comprobables, excepciones y método
de verificación.
